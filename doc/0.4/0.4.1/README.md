# v0.4.1 --- Documentation and Release Gate

## 概要

v0.4.1 は、公開済み v0.4.0
で欠落していた版別開発記録を補完し、今後のリリース整合性を機械的に確認する
Release Gate を導入するメンテナンスリリースです。

アプリケーションの機能および UI の変更はありません。公開済みの v0.4.0
タグは変更せず、v0.4.1 を独立したパッチリリースとして公開します。

## 1. v0.4.0 開発記録の補完

v0.4.0 の公開後監査で、従来のリリースで継続していた
`doc/0.x/0.x.x/README.md` の版別開発記録が v0.4.0
だけ欠落していることを確認しました。

そのため `doc/0.4/0.4.0/README.md` を追加し、v0.4.0
で実施した以下の内容を記録しました。

-   FFmpeg / FFprobe の外部依存化
-   Electron / sharp の更新
-   Windows パッケージ用アプリケーションアイコン
-   Source-only リリースへの変更
-   公開リリース監査で実施した修正
-   v0.4.0 の検証内容

履歴上に存在しない当時のスクリーンショットは後から作成・流用していません。

## 2. Release Gate の導入

リリース前の確認を人手やレビュー結果だけに依存しないよう、`scripts/release-gate.js`
を追加しました。

`npm run release:gate` で、リリースに必要な整合性を機械的に確認します。

主な確認項目は次のとおりです。

-   `package.json` と `package-lock.json` のバージョン整合
-   CHANGELOG に記載された各リリースと版別開発記録の対応
-   版別文書から参照されるローカル画像の存在
-   Apache License 2.0 と `LICENSE` の整合
-   Git worktree の状態
-   `git diff --check`
-   `test/*.test.js` の自動テスト

## 3. バージョン管理

v0.4.0 は既に公開済みのリリースであるため、既存の `v0.4.0`
タグは公開時のコミットを指したまま保持します。

今回の修正は新しいパッチリリース `v0.4.1` として公開します。

## 4. 検証

v0.4.1 のリリース工程では Release Gate
を実行し、バージョン、文書、ライセンス、Git
状態、自動テストの整合性を確認します。

## スクリーンショット

v0.4.1
は文書およびリリース工程の修正のみで、アプリケーション画面の機能やレイアウトに変更はありません。

そのため v0.4.1 専用の新規スクリーンショットは追加していません。
