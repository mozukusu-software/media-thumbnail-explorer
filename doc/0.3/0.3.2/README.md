# v0.3.2 — Network Resilience and Video Seeking

## 概要

v0.3.2 は、UNC ネットワーク共有の切断やアクセス失敗に対する処理を強化し、ネットワーク共有をより安定して利用できるようにするバージョンです。

あわせて、動画プレビューのシーク機能を修正し、全画面表示終了時の画像ビューアー処理や開発用 DevTools ショートカットを追加しました。

## 1. ネットワーク共有の異常系処理

UNC 共有へアクセスできない場合のエラー処理を改善しました。

- 切断された UNC 共有へのアクセス失敗を適切に処理
- 利用不能な共有でエラーダイアログが重複して表示される問題を修正
- 応答しない UNC 共有からの復帰処理を確認
- ネットワーク共有復旧後に再びアクセスできることを確認

## 2. 動画シーク機能の修正

動画プレビューでシークできなくなる問題を修正しました。

ローカル動画の再生 URL を直接 `file:` URL として扱うことで、動画のシーク操作を正常に利用できるようにしました。

## 3. 全画面表示終了時の画像ビューアー

画像を全画面表示している状態で全画面表示を終了した場合、画像ビューアーも閉じるように修正しました。

## 4. DevTools ショートカット

開発および問題調査に利用できる DevTools のキーボードショートカットを追加しました。

## 5. 実機退行テスト

Windows 実機で次の項目を確認し、正常であることを確認しました。

- UNC 共有の切断時のエラー処理
- 利用不能な UNC 共有でエラーダイアログが重複しないこと
- UNC 共有復旧後の再アクセス
- 応答しない UNC 共有からの復帰
- ローカル動画の再生
- 動画プレビューのシーク
- 全画面表示終了時に画像ビューアーが閉じること
- DevTools キーボードショートカット

実装コミットとテスト結果コミットは従来どおり分離して Git 履歴へ記録しています。

## スクリーンショット

v0.3.2 はネットワーク共有の異常系処理と既存機能の修正が中心のため、新規スクリーンショットは追加していません。
