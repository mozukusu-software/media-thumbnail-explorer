# v0.3.0 — Storage Provider Foundation

## 概要

v0.3.0 は、今後のネットワークドライブ対応に向けてストレージアクセスの基盤を整理するバージョンです。

この段階では UNC パスや切断時処理などのネットワーク固有機能は追加せず、既存のローカルファイル処理を Storage Provider の後ろへ移動します。画面、preload、IPC チャンネル、ローカル閲覧時の挙動は変更しません。

## 1. Local Storage Provider

`src/storage/local-storage-provider.js` を追加し、Electron のメインプロセスに直接記述されていた次の処理を移しました。

- Windows のローカルドライブ列挙
- フォルダー列挙
- 子フォルダー有無の確認
- 画像・動画ファイルの列挙

メディア URL の生成や Electron IPC の登録は引き続き `src/main.js` 側が担当します。これにより、ストレージアクセスと Electron 固有処理の境界を分離しています。

## 2. 互換性方針

v0.3.0 では既存 UI から見えるインターフェースを維持しています。

- Renderer の変更なし
- preload API の変更なし
- IPC チャンネル名の変更なし
- ローカルドライブ／フォルダーの表示仕様を維持
- 画像・動画の一覧、サムネイル、プレビュー動作を維持

## 3. 実機退行テスト

Windows 実機で次の項目を確認し、すべて正常であることを確認しました。

- アプリケーション起動とローカルドライブ表示
- 複数階層のフォルダーツリー展開
- 子フォルダー有無に応じた展開矢印
- 画像サムネイル表示
- 動画サムネイル表示
- シングルクリックによる画像プレビュー
- ダブルクリックによる全画面表示
- 全画面表示中の `←` / `→` 移動
- 動画を OS の既定アプリケーションで開く処理
- ツールチップ表示
- 再起動後の最後に開いていたフォルダー復元
- 個別ファイルのプレビューを復元しない既存仕様

実装コミットとテスト結果コミットは従来どおり分離して Git 履歴へ記録しています。

## 4. v0.3.x の次段階

Storage Provider 基盤の確認後、次の段階でネットワークドライブ対応を追加する予定です。

- v0.3.1: UNC パス登録
- v0.3.2: 切断、権限エラー、タイムアウトへの対策

## スクリーンショット

v0.3.0 は内部基盤の変更が中心で UI 変更を含まないため、新規スクリーンショットは追加していません。
